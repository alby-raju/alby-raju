## What interests me

I like the engineering decisions behind dependable software: how to evolve an existing system, keep abstractions useful, handle failure without losing context, and make a tool feel simple without hiding its limitations.

I also enjoy exploring new technologies through hands-on projects. My recent public work takes that curiosity into Swift and native macOS development.

## Featured public project

### [Rill](https://github.com/alby-raju/Rill)

A native macOS API workbench built with **Swift and SwiftUI**. It brings request editing, environments, response inspection, collection workflows, and reviewed imports into a local workspace.

The project explores the details I care about: recoverable editing, Keychain-backed credentials, explicit validation, bounded resource use, and automated tests.
